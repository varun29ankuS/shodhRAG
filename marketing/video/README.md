# Shodh launch video

Remotion project for the launch video. It has captions only and no voice. The music is generated in code.

| Composition | Size | Length | Output |
|---|---|---|---|
| `ShodhLaunch` | 1920×1080 @ 30 fps | 75 s, scenes 1–10 | `npm run render` → `out/shodh-launch.mp4` (H.264, CRF 18) |
| `ShodhLaunchVertical` | 1080×1920 @ 30 fps | 67 s, scene 8 dropped, scenes 4–7 reframed | `npm run render:vertical` → `out/shodh-launch-vertical.mp4` |
| `ShodhLoop` | 960 px wide GIF, 15 fps | 15 s, scenes 4–6 condensed | `npm run render:gif` → `out/shodh-loop.gif` |

## Setup

```sh
npm ci
npm run studio   # preview in the browser
```

The first render downloads Remotion's headless browser. After that, rendering makes no network calls: fonts (Geist, Noto Sans Devanagari) are bundled from `node_modules`, and the music (`public/music/shodh-ambient.wav`) is generated by `npm run music`, which the render scripts run first.

## Adding footage

Scenes 4–9 show footage. Until a scene has footage, it renders a labelled placeholder.

1. Put the files in `public/footage/<scene>/`. A scene takes one of:
   - one MP4/WebM clip, at least as long as the scene;
   - PNG/JPG stills, shown in turn with cross-fades;
   - a numbered PNG sequence.

   Capture at 16:9, ideally 2560×1440, so the zooms stay sharp.
2. List them for that scene in `public/footage.json`:
   - a clip or stills go in `"files": ["clip.mp4"]`;
   - a sequence goes in `"sequence": { "pattern": "frame-%04d.png", "count": 240, "start": 1, "fps": 30 }`.
3. Adjust the camera in `"keyframes"`:
   - `at` is the point in the scene, from 0 to 1;
   - `focus` is the area in footage coordinates (0–1) that the zoom centres on;
   - `scale` is the zoom at that point.

   The camera eases between keyframes. In the vertical cut, the footage is cropped around the same focus.

No code changes are needed. Re-render to see the result.

## Notes

- `out/` and the generated music are not committed.
- The GIF must stay at or under 8 MB. With real footage, check its size after rendering. If it is too big, raise `--every-nth-frame` or lower `--scale` in `render:gif`.
